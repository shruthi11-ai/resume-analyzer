# AI Resume Analyzer 🤖

An AI-powered resume analyzer built using HTML, CSS, JavaScript and Anthropic's Claude API.

## Features
- Upload PDF or TXT resume
- Get scores for ATS Fit, Impact, Clarity
- AI-generated strengths & weaknesses
- Hiring manager verdict
- Real-time feedback

## Tech Stack
- HTML, CSS, JavaScript
- Anthropic Claude API (claude-sonnet)
